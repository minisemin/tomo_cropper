# tomo_cropper
Crop multiple tomograms with the same prefix together, regardless of their binnings. Save cropping history to reapply the same crop with newly generated tomograms.

Use bin 4+ tomograms for faster GUI loading and view, and crop lower ~ original tomograms using the same dimensions.

This code is 100% generated by Claude

---

# Features

- Only supports .mrc file
- File names should be "[prefix]_[Option]_Vol_b[n].mrc"
  - Options include: Nothing, ODD, EVN
  - n: binning number. Cropper will find the original bin 1 size by multiplication, and crop multiple tomograms.
